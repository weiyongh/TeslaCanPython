# TM3-008 关门落锁完整下电：车型条件化基线分析

## 实验信息与适用范围

- 用途：正常基线数据采集；评价关门、NFC落锁后的条件化下电过程，不作车辆故障判断。
- 车辆：Tesla Model 3，上海产2021款，2021年5月出厂，标准续航，55 kWh，后驱。
- 完成状态：PARTIAL；范围：THIS_EXPERIMENT_ONLY。
- ASC正式Analysis Window为0–660秒；脚本为0–600秒，时间覆盖满足并有60秒余量。

## 事实与关键证据

- CAN内部观察到驾驶门CLOSED→OPENED→CLOSED；关门后保持UNLOCKED，随后ACTIVE_NFC_LOCK与两项LOCKED反馈同步出现。
- 落锁后，UI Ready消费者状态先退出；GTW分域asleep候选随后出现；最终vehiclePowerState进入OFF，高压接触器与DCDC执行退出。
- BMS总接触器在282.2451秒进入OPENING、282.5436秒进入OPEN；0x20A正负接触器候选在282.3549秒进入OPENING、283.3549秒进入OPEN。
- 295.8383秒为当前采集域最后一帧，至660秒保持无帧，共364.1617秒；该事实只描述当前采集域。

## 控制关系

- **实测状态推进**：门开 → 门关 → NFC落锁/LOCKED → Ready消费者退出 → 分域asleep候选 → OFF → 接触器/DCDC退出 → 采集域静默  
  证据：`VCLEFT_frontLatchStatus`（`0x102`）；`VCSEC_lockRequestType`（`0x339`）；`VCSEC_simpleLockStatus`（`0x339`）；`UI_readyForDrive`（`0x353`）；`VCFRONT_vehiclePowerState`（`0x221`）；`BMS_contactorState`（`0x212`）；`PCS_dcdc12VSupportStatus`（`0x224`）；`报文频率(派生)`（`derived`）  
  只表达CAN内部实际顺序，不主张完整控制因果。
- **高压执行与物理响应**：总接触器及正负接触器候选打开；放电状态候选短时ACTIVE；0x132电压字段快速下降  
  证据：`BMS_contactorState`（`0x212`）；`HVP_packContPositiveState`（`0x20A`）；`HVP_packContNegativeState`（`0x20A`）；`PCS_dcdcHvBusDischargeStatus`（`0x224`）；`BMS_packVoltage`（`0x132`）  
  可靠下游母线定量Signal缺失。
- **低压能源响应**：DCDC支持最终ACTIVE→IDLE，低压输出电流候选归零  
  证据：`PCS_dcdc12VSupportStatus`（`0x224`）；`PCS_dcdcLvBusVolt`（`0x2B4`）；`PCS_dcdcLvOutputCurrent`（`0x2B4`）  
  无外部12V测量。

## 基线结论

- 本次建立了关门未锁、NFC落锁/锁止反馈、Ready消费者状态退出、高压/DCDC最终退出及采集域静默的条件化CAN基线。
- 完整请求—许可—执行链尚未建立；实验完成状态保持PARTIAL。

### Evidence Assessment

- `ER-01`：`INSUFFICIENT_EVIDENCE` — 区间起始UI_readyForDrive=1、门闩CLOSED、车辆UNLOCKED、BMS接触器CLOSED、DCDC支持ACTIVE且通信活跃；边界：Ready、高压和DCDC起始状态有CAN支持，但DI_gear无样本，P挡及外部READY事实仍缺口。
- `ER-02`：`INSUFFICIENT_EVIDENCE` — 驾驶门在7.9845秒CLOSED→OPENED，并在29.6561秒OPENED→CLOSED；边界：开关门反馈已观察；VCLEFT_frontOccupancyStatus无帧，离座动作及Observed Event Time不能由门闩替代。
- `ER-03`：`SUPPORTED` — 关门后车辆维持UNLOCKED；33.3626秒VCSEC_lockRequestType出现ACTIVE_NFC_LOCK，simple/vehicle锁状态同步转为LOCKED；边界：支持CAN域内关门未锁与NFC落锁/反馈的区分；UI_lockRequest全程IDLE且不承担钥匙卡REQUEST，外部灯光/声音反馈仍属ER-10 GAP。
- `ER-04`：`INSUFFICIENT_EVIDENCE` — UI_readyForDrive在122.8397秒由1转0；VCFRONT_vehiclePowerState在282.1605秒由CONDITIONING转OFF，随后接触器与DCDC退出；边界：观察到消费者状态和系统结果，但没有直接下电REQUEST/PERMISSION/COMMAND；BMS_hvState语义验证失败。
- `ER-05`：`INSUFFICIENT_EVIDENCE` — BMS总接触器282.2451秒OPENING、282.5436秒OPEN；0x20A正负接触器282.3549秒OPENING、283.3549秒OPEN；放电候选282.4645到282.7644秒ACTIVE；0x132电压字段快速下降；边界：PCS_dcdcHvBusVolt继续SEMANTIC_VALIDATION_FAILED；0x132字段的Pack端物理定位与下降行为冲突，因此接触器执行已支持，但下游母线定量物理响应仍为GAP。
- `ER-06`：`SUPPORTED` — PCS_dcdc12VSupportStatus曾在175.4707到185.2708秒短暂IDLE后恢复ACTIVE，并在282.2645秒最终转IDLE；DLC6低压输出电流候选随后归零，母线电压候选约7.77到14.06 V；边界：仅支持PCS侧DCDC/低压响应；PCS_dcdcMainState语义失败，且没有外部12 V测量。
- `ER-07`：`INSUFFICIENT_EVIDENCE` — 可重建门开→门关→NFC落锁/锁止反馈→Ready消费者状态退出→GTW分域asleep候选→SYSTEM_RESULT OFF→接触器/DCDC退出→BMS总线休眠候选→末段静默的实际顺序；边界：占座以及直接需求/许可/命令层仍缺失，不能形成完整请求—许可—执行链，也不从时间先后推断控制因果。

## 证据边界

- Planned Time、CAN Observed Time与缺失的Observed Event Time严格分开；不反推人工动作精确时间。
- 当前采集域通信静默不得表述为整车全部ECU下电或整车完全休眠。
- ER-10外部现场证据GAP保持不变，任何CAN Candidate均不能替代。
- PCS_dcdcHvBusVolt语义验证失败；0x132电压字段物理位置冲突，ER-05下游母线证据保持不足。
- 结论限定为TM3-008、THIS_EXPERIMENT_ONLY，不迁移为车型级永久Signal语义。

## 结论与下一步建议

- 保留本次已支持的关门落锁、高压/DCDC执行及网络退出过程证据。
- 如需闭合ER-05，最小补采应增加可靠接触器下游高压母线物理测量或经独立验证的定量Signal。
- 如需闭合ER-09/ER-10，应补充现场记录/App时间锚点与不少于10分钟的连续无干预静默观察。
- 当前不进入车辆故障诊断树，也不修改共享方法论。
