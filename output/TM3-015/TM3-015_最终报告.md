# TM3-015 直流快充基线分析报告

**用途：** 正常基线采集  
**适用范围：** 本车、本次实验、当前实测窗口  
**最终状态：** `CLOSED_WITH_PENDING_EXTERNAL_CALIBRATION`

## 结论

TM3-015已完成并关闭。本次建立了直流充电建立、短稳态和主动停止退出的时序基线，并将173.73–233.23 s稳定窗口的Pack侧能源响应升级为**实验级定量基线**：

`364.90 V / 193.88 A（充入Pack为正）/ 70.75 kW`

Pack定量值由`0x132`平滑电流、同帧独立未滤波电流、Pack V×I以及累计充电量差分多路交叉支持。桩/CP侧电压约365.4 V具有较强定量支持；`CP_evseOutputDcCurrent`的建立、稳定和归零时序可用，但当前128.108 A不能作为可信桩端实际电流。因此本次尚未建立桩端到Pack的完整定量能源链或效率基线。

## 事实与控制关系

车辆侧可见充电状态约115.3922 s建立；候选直流电压约140.03 s建立，直流电流约145.03 s开始建立。173.73–233.23 s形成59.50 s短稳态。停止候选约245.7336 s出现，直流电流约246.23 s归零，车辆充电状态约246.3925 s退出。

多DBC补充证据在本实验范围内支持以下部分车辆侧链路：

`DC链路允许上电候选 → 快充接触器闭合请求 → 辅助触点闭合反馈 → 高压充电阶段候选 → 直流电压建立 → 直流电流建立`

边界外扫码、付款和桩平台接受仍只作为外部事件，不写成车辆内部控制节点。现有证据不能还原完整协议协商或OEM充电许可算法。

## 能源链定量结论

### Pack侧实验级定量基线

- Pack电压均值：364.901 V；
- 平滑Pack电流：193.880 A，正文按充入Pack为正；
- 同帧未滤波Pack电流：193.782 A；
- 平滑电流派生功率：70.747 kW；
- 未滤波电流派生功率：70.711 kW；
- 独立累计充电量候选在59.003 s内增加1.158 kWh，折算70.655 kW；
- UI SOC由28.2%升至30.5%，只作数量级旁证，不作为精确功率测量。

以上不同位段、不同缩放及累计量证据在约70.7 kW处闭合，支持Pack侧定量基线。原始DBC符号为负值充电；人读报告统一转换为“充入Pack为正”，不修改底层原始数据。

### `0x29D` CP侧

`CP_evseOutputDcVoltage`稳定段约365.408 V，与Pack电压接近，具有较强定量支持。

`CP_evseOutputDcCurrent`按当前DBC解得128.108 A、派生46.812 kW。其建立、稳定和归零时序可信，但该功率与Pack双电流字段及累计电量不能闭合。DBC声明DLC 4、ASC实际DLC 5，但电流、电压和Stale字段均位于前4字节，第5字节全程为0，因此DLC差异本身不是128 A问题的解释。当前最可能存在factor或版本/字段语义适配问题；没有独立标定前不得修改DBC，也不得把128.108 A当作可信桩端Actual。

### `BMS_chgPowerAvailable`

本车TM3-015优先采用`Model3CAN.dbc`的bit 40、11位、factor 0.125候选定义，稳定段约72.98 kW。该定义在非充电阶段准确得到raw 2047=`SNA`，充电过程中由约69.4 kW爬升至约73.0 kW，且Pack Actual约70.75 kW未超过该能力候选。

当前中文语义为：**BMS计算的当前可用充电功率/充电能力上限候选**。保持P1、实验级中高置信度；不等于Request或Actual，也不认为已经建立完整`Available→Actual`控制关系。ONYX bit 38得到的35.9 kW属于位段适配失败，不再作为本车有效能源数值。

## 热管理与状态边界

`BMS_modelTMax`候选由约33.5°C升至35.0°C；最低温度、部分接口温度及多个热管理目标/执行字段仍有SNA、越界、复用页或变化率异常。本次没有建立“Pack热状态—请求—执行—温度响应”闭环，不再继续扩展热管理Signal。

挡位和系统状态只作为本次条件背景，不用于反推OEM完整充电许可规则。连接、锁止、解锁和拔枪仍缺少独立实际事件记录。

## 证据边界

本项目DBC来自第三方逆向、社区整理及不同版本来源，不是Tesla官方定义。关键Signal遵循项目Signal Validation流程；P等级只表示本实验重要度，不代表车型语义成熟度。当前Signal成熟度：

- `0x132 / BMS_packCurrent`：`STRONGLY_SUPPORTED`，适用于TM3-015 Pack侧实验级定量基线；
- `0x29D / CP_evseOutputDcCurrent`：`TIMING_ONLY_VALID`，定量语义未验证；
- `BMS_chgPowerAvailable` bit40：`PARTIALLY_VALIDATED`，实验级能力上限候选。

本报告不据DBC适配冲突进入车辆故障诊断树。TM3-015至此停止分析，后续回到新的实车实验。
