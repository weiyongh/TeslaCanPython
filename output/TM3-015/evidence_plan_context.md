# TM3-015 Draft Evidence Plan Context

## 1. 计划状态与用途

- 计划状态：`APPROVED`
- 用途：正常基线采集，不是故障诊断。
- 车辆：上海产 2021 款 Tesla Model 3，2021 年 5 月出厂，标准续航，55 kWh（车型参数），后驱。
- 原始数据：`input/can_20260831102614_TM3-015_直流快充采集.asc`；本阶段仅确认文件存在，未读取、解码、统计或检查报文覆盖。
- 本计划及人工审核只适用于 TM3-015；正式Approved范围为`THIS_EXPERIMENT_ONLY`，不自动写回车型知识。

## 2. 实验目的与系统边界

实验目的：建立一次短时直流快充中“充前背景—充电口开启—插枪/锁止—扫码授权—直流充电条件与许可—电流建立—短时运行—主动停止—电流退出—解锁/拔枪”的车型 Signal 投射、状态转换、数值与关键时序基线。

系统边界内：车辆充电口控制器/连接检测、车辆侧充电状态与许可、BMS 高压及充电状态、Pack 能源响应、可见的低压和热状态。

边界外输入：人工开门、插枪、扫码/付款、桩端接受启动、人工停止入口、拔枪；这些事件必须来自实际事件表、播报、录像、桩屏或订单记录，不能仅由脚本名义时间或 CAN Signal 反推。

边界外对象：运营商平台、支付网络、桩内部控制和车桩协议中当前车内 CAN 域不可见部分。缺少握手 Signal 不等于没有握手，平台失败不直接判作车辆故障。

边界外物理观测：桩端电压、电流、功率、累计电量、枪锁实际释放及拔枪时刻。桩屏与手机网络延迟不用于毫秒级时序判断。

## 3. Control Relationship View（Draft）

边界外事件轴（不属于车辆内部控制链）：

`人工开充电口 → 人工插枪 → 扫码/付款/平台处理 → 桩端接受启动 → 人工/平台停止 → 桩端确认停止 → 人工拔枪`

上述事件只用于建立“外部事件 → 车辆可观测响应”的时间对应关系，不等同车辆内部请求、许可或决策节点。

车辆内部可观测充电主链：

`连接检测/锁止 → 可见通信/协商 → 整车状态 + 电池状态 + 安全条件 → 车辆充电条件判断/许可 → 高压直流充电状态 → 直流电流建立`

车辆内部可观测停止链：

`外部实际停止时刻 → 车辆侧候选停止/关断状态变化 → 充电状态退出 → 直流输出电流退出 → 锁止状态释放`

能源交叉验证：

`桩侧直流电压/电流/功率 ↔ CP可见桩输出电压/电流/派生功率 ↔ Pack电压/电流/同帧V×I功率`

条件与能力背景：

`挡位/整车系统状态、SOC、Pack温度、BMS可用充电功率、低压母线与告警`

热管理条件/响应副线：

`Pack热状态 → 充电能力条件 → BMS热管理请求/目标 → 冷却液/泵/阀/Chiller/压缩机等候选执行反馈 → 快充过程温度响应`

热管理副线独立表达，不强行串入单一主控制链，也不因执行器Signal出现就反推OEM完整热管理策略。

控制节点不会因缺少直接 Signal 被删除；分析时分别标记直接观测、部分观测、上下游间接支持或本次未观测。

## 5. 关键审核边界

1. `CP_*` 连接、协商和直流输出定义主要来自社区 DBC，尚未在本车 TM3-015 数据中验证，均按候选处理。
2. `CP_gbState` 在不同 DBC 中存在位段/位宽差异；即使数值可解码，也必须先完成版本适配复核。
3. `0x27D/0x2BD` 的 EVSE 电流/功率能力字段只见于 `dbc/Model3CAN.dbc`；当前 `input/tesla_model3_ONYX.dbc` 将 `0x27D` 定义为其他报文，属于严重节点绑定冲突，Draft 默认仅列为 P2 专项候选。
4. `BMS_packCurrent` 在本地 DBC 中存在符号与偏置冲突；沿用既有车型项目经验不等于本实验自动确认，审核后仍需在工程审计中做定义对照。
5. 充电桩输出功率、CP侧派生功率和Pack净充电功率属于不同测量边界；不同步、辅助负载和滤波均可产生差异，本实验不计算充电效率。
6. 快充不是 OBC 交流整流过程；PCS交流充电字段不进入本次核心主线。
7. `DI_gear`和`DI_systemState`只作为本次整车状态/条件背景；本次可见P挡或某系统状态不能自动升级为OEM充电许可充分条件。
8. 热管理候选均为新增待审项；未完成人工审核前不进入拟Approved核心计划。

## 6. 第二轮审核后固定规则

- `DI_gear`、`DI_systemState`作为P2整车状态/条件背景，只陈述本次状态与充电过程共存。
- 热管理P1主干和P2专项候选均进入本实验Approved Plan，但保持候选语义和原置信度。
- `CP_pinTemperature1/2/3`属于“充电接口热状态”专项，不并入Pack热管理副线。
- `CP_chargeCableSecured`与`CP_latchState`均保留P0，但不预设语义等价；专项比较插枪、锁止、停止、解锁和拔枪附近转换。
- 人读功率统一“充入Pack为正”；原始ASC/DBC值、原始符号定义与转换过程保留在工程审计，不修改原始数据。
- 候选Signal不可读、复用页不成立或方向明显不符时，Assessment使用`INSUFFICIENT_EVIDENCE`并记录`SEMANTIC_VALIDATION_FAILED`原因，不强行解释。
