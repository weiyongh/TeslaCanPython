# TM3-009 制动输入与请求/实际扭矩趋势

日期：2026-08-31。目的：在实测制动输入杆行程及IBST驾驶员制动状态的时间轴上，判断后电驱请求扭矩和实际扭矩的方向、变化趋势与差值。保留车速、挡位、电门、Pack功率背景，不将“踩刹车”预设为负电机扭矩。

**结论：两次停车与一次低速补踩呈现三种不同过程。第一次停车是负扭矩逐步回零；补踩过程中扭矩始终为正，先升后降再恢复，实际扭矩的变化与请求不完全同步；第二次停车是小负扭矩经过短暂小正值后归零。后电驱扭矩不是整车总制动力。**

## 1. 对齐方式与范围

- 采集仍为`input/can_20260831090233_TM3-010_中等负载加速采集.asc`，按工况归入TM3-009，未改原始文件。
- 请求与实际扭矩来自ONYX定义的同一0x108帧，周期约100 ms，使用原生样本逐帧配对。
- 行程、IBST状态来自Model3CAN定义的5字节0x39D，周期约40 ms；其余信号沿用本次已解码结果。
- 对齐仅取扭矩时刻之前的最近样本。行程/IBST允许最大年龄80 ms，车速50 ms，电门、挡位和功率30 ms，VCLEFT开关150 ms；缺失时留空。实际样本年龄逐行保留。
- 按IBST状态ON划定观察窗口，不将状态边沿等同于液压压力或制动力建立时刻。状态阈值、过滤、行程零点及不同报文异步都可能影响对齐。
- 5次IBST制动状态区间均已审查；重点比较3次车辆运动中的制动。两次挂D前的制动主要用于确认静止与松刹车后的低速正驱动，不与运动制动混算。
- 以下Nm值依赖当前公开DBC缩放；未获得厂家允许误差、真实轮端摩擦扭矩或压力，不据此做制动安全性认证或内部控制策略定论。

## 2. 第一次停车：负扭矩变小，随后归零

IBST从75.036秒报告制动；制动前1秒请求扭矩已经是−622～−528 Nm，说明回收早已存在，不能把负扭矩建立归因于这次脚刹。

| 时间（秒） | 请求/实际扭矩（Nm） | 输入杆行程（mm，前向保持） | 车速（km/h） |
|---|---|---:|---:|
| 75.061 | −510 / −510 | 0.594 | 20.00 |
| 76.060 | −270 / −292 | 5.047 | 14.40 |
| 77.460 | 0 / −6 | 5.109 | 7.36 |

75.036～78.539秒的35个扭矩样本中，请求24个为负、11个为零，无正值。请求与实际整体都向零收敛；77.460秒请求已经为0、实际仍为−6 Nm，是过渡样本，不能将一帧差异当作故障。之后两者都为0，而车辆仍继续减速。

这段说明：在该次脚刹与减速过程中，电驱回收扭矩没有随行程增加而持续变得更负。不能推出“脚刹越深回收越强”。车速下降、低速驱动策略及摩擦制动都可能参与；缺少压力/轮端制动量，不能定量拆分各自贡献。

## 3. 低速补踩：保持正扭矩，差值明显增大

IBST区间98.037～99.957秒，电门全程为0、D挡，车速约0～1.12 km/h（个别−0.16/−0.08值作为近零测量现象保留，不据此认定倒车）。该段属于先前已建立的低速正驱动背景。

| 时间（秒） | 输入杆行程（mm） | 请求/实际扭矩（Nm） | 车速（km/h） |
|---|---:|---|---:|
| 98.059 | 0.406 | +342 / +368 | 0.48 |
| 98.259 | 0.641 | +382 / +388 | 0.72 |
| 98.659 | 3.922 | +364 / +426 | 1.12 |
| 98.759 | 3.922 | +344 / +412 | 0.96 |
| 99.359 | 3.875 | +106 / +154 | 0.00 |
| 99.559 | 3.156 | +62 / +64 | −0.08 |
| 99.859 | 1.844 | +256 / +260 | 0.24 |

请求先继续升到+382 Nm，随后下降至+62 Nm，再在行程回落时恢复。实际扭矩先升到+426 Nm，下降阶段多高于请求；整个区间19个请求样本和实际样本都为正，没有转入负扭矩。

此处必须修正过度概括的“始终紧密跟随”：方向一致，但下降期间存在明显动态差值。实际−请求平均约+30.32 Nm，平均绝对差35.37 Nm，最大68 Nm（98.759秒，344/412 Nm）。这是值得保留的现象，不把普通无制动加速段1～2 Nm的平均绝对差直接当成本段标准。

可能涉及低速驱动控制与制动的交互、执行/估算动态或DBC适配；目前只能确认趋势及差值。100 ms报文频率不足以确定内部控制延迟，不能由波形错开直接宣称响应超时或控制故障。

IBST从148.438秒报告制动，比VCLEFT开关149.034秒早约0.596秒。制动前1秒请求已为−36～−20 Nm，属于此前减速过程的尾段。

148.438～150.434秒共20个扭矩样本：请求8负、8零、4正。短暂小正扭矩并非只有实际值单边跳变，请求本身也为正；同时车速仍下降，所以不能把小正扭矩直接解释为车辆异常加速。

该段Pack功率已保持净放电约+0.28～+0.73 kW，即便电驱仍有小负扭矩，也不足以让整个Pack净回充；辅助负载等会影响能量净流向。不能仅用Pack电流正负判定摩擦制动是否发生。

## 6. 如何补充已有控制树说明

- 制动输入：使用输入杆行程与状态辅助解释，不能只看开关或把位移当作力。
- 请求扭矩：踩刹车后仍可能为正、负或零，必须结合起始车速和已有驱动/回收状态。
- 实际扭矩：检查同帧符号、趋势和动态差值；本次低速补踩是需继续验证的差值较大窗口。
- 车速/能源反馈：车辆减速不要求电机扭矩必为负，电驱负扭矩也不保证Pack净回充。

这些均为已有变量的实验说明，不新增控制树分支。未确认新的制动仲裁逻辑或摩擦/回收分配规律。
