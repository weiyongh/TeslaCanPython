# TM3-017 Evidence Assessment

**Experiment：** `TM3-017`

**Round：** `S0030`

**Vehicle：** `TESLA-M3-SOP5`

**用途：** 正常基线

**Assessment状态：** `COMPLETE_WITH_GAPS`

**信息边界：** `STRICT_NO_DBC_RAW_PAYLOAD_ONLY`

## 当前结论

本轮六项核心Evidence Requirement均为`SUPPORTED`。在本车、本Round和本次现场条件下，车辆端充电电流设置从32 A调低到16 A并恢复到32 A后，实际交流取电出现方向一致、可区分且可逆的下降与恢复；调低及恢复后均形成超过30秒的稳定观察窗口，过程中没有已观察到的停充、重启或重连。

因此，本轮支持以下实验级控制关系：

```text
操作者改变车辆充电电流设置
→ 车辆页面接受并保持新设置
→ 实际交流电流与功率经过响应过程下降或恢复
→ 新设置下形成持续充电稳定窗口
```

该结论不确认车辆内部电流Target、能力限制、仲裁、OBC执行字段或任何具体CAN Signal身份。

窗口由程序基于实际Event/照片Clock计算，并主动避开两次阶跃边沿：

| 窗口 | ASC相对时间 | 时长 | 外部锚点 | 原始ASC表现 |

| W1 初始高设置 | 5.000–75.000 s | 70.000 s | E01-P01在32.854 s确认32 A实际/设置 | 多个匿名原始位置维持高位 |
| W2 低设置 | 90.763–208.268 s | 117.505 s | E03-P01确认16 A实际/设置；终点取E06提示 | 多个匿名原始位置维持低位 |
| W3 恢复高设置 | 227.478–330.000 s | 102.522 s | E06-P02确认32 A实际/设置；排除E06-P01的21 A中间态 | 多个匿名原始位置恢复高位 |

ASC共339.3012秒、770182帧、278个CAN ID。通用筛选在原始byte层得到48个`HIGH_LOW_HIGH_RAW_BYTE`候选；该数字包含计数器、复用或偶然共变的可能，不代表48个Signal，更不代表48项独立Evidence。

较清晰的匿名行为例子包括：

| 原始位置 | W1/W2/W3中位原始值 | 两次边沿表现 | 允许的解释 |
| --- | --- | --- | --- |
| `0x333 / DLC5 / byte1` | 32 / 16 / 32 | 调低提示后约1.459秒开始变化、约3.865秒到低位；恢复提示后约3.760秒开始变化、约5.878秒回高位 | 仅为与阶跃数值同向的原始层级候选 |
| `0x252 / DLC8 / byte4` | 244 / 104 / 244 | 两侧均呈分段变化并返回原值 | 仅为可逆强度响应候选 |
| `0x204 / DLC8 / byte4` | 159 / 0 / 160 | 调低侧约4秒到低位；恢复侧明显较晚并呈连续爬升 | 仅为较慢响应候选；与E06-P01中间态在时间上相容 |

## Evidence Boundary

1. 本轮没有读取、检索或使用任何DBC、DBC镜像、既有Signal解析结果、历史Signal答案或其派生材料。
2. ASC结论停留在`CAN ID + DLC + zero-based byte offset + raw value`。不得将任何候选写成电流、电压、功率、设置、请求、实际、能力或仲裁Signal。
3. 页面上的“电流设置”“实际电流”和“可用上限”是三个独立Recognition字段；本轮设置16 A时可用上限仍为32 A，不能把两者合并。
4. E03-P02在车辆已显示16 A之后仍显示32.4 A，说明配套应用的刷新/缓存时序未知。它不推翻后续多源低位，但阻止用该应用估算精确响应延迟或做严格同步定量闭环。
5. Event Clock是VoiceRunner动作提示锚点，不是人工触控完成时刻。原始变化相对Event的时延只能作为提示后响应范围。
6. “无停充、重启或重连”是基于现场记录、连续Event序列、多张持续充电页面和原始行为连续性得出的本Round判断；没有连续外部视频，也没有已确认连接Signal。
7. W1/W2/W3的原始稳定性不能单独证明物理量稳定；其效力来自与人工确认页面读数联合使用。
8. 结论仅适用于`TESLA-M3-SOP5`、S0030、本次SOC约85%至86%、本次EVSE和未记录异常的现场条件，不外推到热限制、SOC限制、桩侧限流或其他车辆。

## 下一步判断

TM3-017不需要整体重采。六项核心ER均得到支持，本轮足以保留为带条件的交流慢充电流控制基线；完成状态为`COMPLETE_WITH_GAPS`，缺口集中在应用刷新实时性、精确人工触控时刻和内部节点不可观测性，不影响方向性与可逆性主结论。

当前不应进入故障诊断树，也不应修改正式控制树。48个原始byte候选中只有少数具备稳定、可逆和边沿时序价值；后续若获授权，适合先做同一盲态边界内的候选去伪与跨Round行为复核，而不是立即赋予Signal语义或启动新的实车采集。
