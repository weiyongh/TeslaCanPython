# 按学习重点重新压缩
上表比较完整，但真正进入你的L3主干，可以压缩成五组。
## 第一优先级：安全生死线
这些必须掌握：
```plain text
单体最高/最低电压
最高/最低温度
PACK电压与电流
绝缘电阻
HVIL
接触器状态
预充状态
母线电压
故障等级
碰撞与紧急断电状态
```
这些变量直接决定：
> 能否上电、是否限功率、是否断开高压。
---
## 第二优先级：对外控制接口
```plain text
SOC
最大允许放电功率
最大允许充电功率
最大允许回收功率
允许充电
允许放电
高压可用
READY许可
冷却请求
加热请求
```
它们是BMS与其他系统发生关系的核心。
可以概括为：
```plain text
BMS对外主要提供：

电池还有多少能量
电池目前能输出多少
电池目前能接收多少
电池是否允许工作
电池是否需要热管理
电池是否出现安全风险
```
---
## 第三优先级：诊断定位变量
```plain text
最高/最低电芯编号
压差
温差
采样有效性
绝缘方向
接触器指令与反馈
预充电压比
通信状态
DTC
故障快照
```
这些帮助你从“报故障”继续收敛到：
> 哪一个区域、哪一条线路、哪一个部件。
---
## 第四优先级：健康与性能
```plain text
SOH
可用容量
可用能量
内阻
一致性
循环次数
累计充放电量
```
用于判断老化、性能衰减和长期趋势，但通常不是高压安全判断的第一入口。
---
## 第五优先级：内部工程与维护数据
```plain text
均衡占空比
详细寿命计数
软件标定参数
生产批次
内部算法中间量
```
这部分遇到具体车型或案例再查，不需要现在展开。
---
