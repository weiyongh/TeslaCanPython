# VoiceRunner V2.1 人工触发增强

## 目标

在保留 V2 定时执行模式的同时，增加人工触发模式，使操作者能够根据现场准备情况决定每个 Event 的触发时刻。

## 模式

- `人工触发：OFF`：保持 V2 行为，按脚本 `plan_time` 自动准备、倒计时并触发 Event。
- `人工触发：ON`：Session 开始后时间连续流逝；除首个“开始采集”Event 外，后续 Event 由操作者点击“下一操作”触发。
- 模式只允许在采集前选择；Session 开始后锁定。

## 人工触发行为

1. “下一操作”由普通标签变为深色背景、白色高反差文字的按钮。
2. 点击被程序接受时，立即记录该 Event 的 `trigger_script_time_us`。
3. Event 状态变为 `triggered`，并成为当前操作。
4. 立即播报 Event 第一行标题，不执行 Event 前的 3—2—1 倒计时。
5. 按钮随即显示再下一个 Event，等待下一次人工点击。
6. 原始 `plan_time_s` 继续显示并保留，但只作为脚本参考，不控制人工模式的触发。

## 保持不变

- Session 开始前的“准备开始采集，3—2—1，开始采集”流程保持不变。
- `script_time` 从 Session 零点连续流逝。
- 拍照、Event/Photo 备注、全程录音、前后台运行、结束采集和 ZIP 导出保持不变。
- “跳过”仍只作用于已经触发的当前 Event，继续使用 `triggered → skipped`，同时保留触发与跳过时间。
- `session.json` 与 `event_timeline.csv` 的 V2 数据合同保持不变。

## UI

- 在原会话状态行增加 `人工触发：ON/OFF` 按钮，不改变中央执行区结构。
- 人工模式运行时，“下一操作”使用深紫蓝背景与白字突出可点击状态。
- 人工模式不使用自动播报暂停，因此“暂停播报”按钮置灰。
- 最后一个 Event 触发后显示“下一操作：已完成”，由操作者点击“结束采集”结束 Session。
