# L3-Charge-Slow-CurrentControl 脚本Reference

**对应Case契约：** [L3-Charge-Slow-CurrentControl Case契约](L3-Charge-Slow-CurrentControl_Case契约.md)  
**用途：** 共享实现的第二个预期输出样例  
**形成日期：** 2026-09-10  
**当前状态：** 已审核通过，作为预期输出Reference；不是正式发布脚本  

## 1. 本次Reference使用的现场条件

- 存在操作者可用的交流充电电流设置入口。
- 是否支持在充电过程中直接调低并恢复，需要在具体Round开始前确认。
- 不假设设置界面同时显示设置电流和实际充电电流。
- 若只显示设置值，实际响应使用现场可用的充电设施显示、配套应用或车辆端充电功率观察。
- 不同显示来源按各自记录时间解释；页面实时性未知时明确备注。

这些条件是生成本份脚本Reference的现场输入，不属于Case契约。

## 2. 有效阶跃执行条件

```text
I_setting_high = 调整前设置值
I_actual_pre   = 调整前稳定实际充电电流
I_setting_low  = 调低后的设置值
ΔI_min         = 足以区别于显示分辨率和正常波动的变化量
```

有效调低阶跃至少满足：

```text
I_setting_low < I_actual_pre - ΔI_min
```

同时要求调低值处于允许设置范围、调低后仍能持续充电、恢复值等于调整前设置值。若无法获得可信的调整前实际电流水平，不能仅根据`I_setting_low < I_setting_high`宣称形成有效阶跃；由电压和功率推算时必须标明为估算。

## 3. Event骨架

```text
开始采集并确认正常充电已经稳定
→ 记录初始设置和实际充电响应
→ 调低充电电流设置
→ 记录低设置下的响应和稳定状态
→ 恢复原充电电流设置
→ 记录恢复后的响应和稳定状态
→ 保存产物并结束本Round采集
```

三个观察窗口之间不得通过停止、重新启动或重新连接建立新的充电过程。

## 4. VoiceRunner脚本Reference

```text
00s   开始采集
      L3-Charge-Slow-CurrentControl：观察充电电流设置调低和恢复后的实际充电响应
      车辆保持P挡，交流慢充已经正常建立
      保持空调、充电上限和其他车辆设置不变
      确认支持在充电过程中直接调整充电电流
      若不能直接调整，记录备注并结束本轮

30s   记录初始状态
      拍摄当前充电页面，记录当前充电电流设置
      记录当前可见的实际电流或充电功率
      充电设施有可见读数时拍摄；否则查看配套应用并记录页面更新时间
      保持当前设置，确认充电状态短时稳定

70s   调低充电电流
      将充电电流设置调到明显低于调整前实际充电水平的数值
      拍摄调低后的设置值
      若无法判断调低值是否低于实际充电水平，暂停并记录，不宣称完成有效阶跃
      调整后不进行其他操作

130s  记录低设置响应
      拍摄当前充电页面
      记录当前可见的实际电流或充电功率
      充电设施或配套应用有可用读数时一并记录
      确认仍在持续充电，不重新启动或重新连接

190s  恢复充电电流
      将充电电流恢复到调整前记录的设置值
      拍摄恢复后的设置值
      恢复后不进行其他操作

250s  记录恢复响应
      拍摄当前充电页面
      记录当前可见的实际电流或充电功率
      充电设施或配套应用有可用读数时一并记录
      确认充电重新形成稳定状态

310s  结束采集
      保存ASC、CANVoiceRunner导出、照片和备注
      检查初始、调低、恢复三个观察窗口均有记录
      记录哪些数值是直接显示，哪些是估算或实时性未知
      结束本轮采集；是否继续充电按现场需要决定
```

## 5. Reference检查点

- 调低值必须形成相对调整前实际充电水平具有判别力的有效阶跃。
- 设置动作和实际响应分别记录，不要求显示或响应同步刷新。
- 初始、低设置和恢复后三个窗口能够前后对照。
- Pack响应是可选增强证据，不增加现场必需节点。
- 脚本不包含Candidate Signal、DBC字段或不可见内部状态判断。
- 本Reference用于校验共享实现输出，不反向定义Case、ER或OR。
