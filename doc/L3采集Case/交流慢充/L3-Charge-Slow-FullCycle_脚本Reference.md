# L3-Charge-Slow-FullCycle 脚本Reference

**对应Case契约：** [L3-Charge-Slow-FullCycle Case契约](L3-Charge-Slow-FullCycle_Case契约.md)  
**用途：** 共享实现的预期输出样例与后续回归Reference  
**形成日期：** 2026-09-10  
**当前状态：** Human Review ACCEPT，作为预期输出Reference；不是具体Round的正式发布脚本  

## 1. 本次Reference使用的现场条件

- 设施为小区商用交流慢充桩。
- 插枪后通过微信扫码启动，不支持定时启动。
- 桩屏开始阶段可显示充电参数，约一至两分钟后暗屏。
- 微信小程序提供充电信息，但数据实时性未经确认，并可在驾驶舱内查看。
- 车辆端充电页面可以显示现场可见的充电状态和参数。
- 正常停止选择车机屏幕，减少手机多任务对VoiceRunner和现场取证的干扰。
- 停止后可能需要独立解锁充电枪；现场使用正常解锁方式。
- CAN数据记录工具不限定具体设备或软件。

这些条件是生成本份脚本Reference的现场输入，不属于Case契约，也不得自动迁移到其他现场条件。

## 2. Event骨架

```text
开始采集并保留动作前CAN基线
→ 开充电口
→ 插枪
→ 记录连接状态
→ 扫码启动并保留桩侧即时读数
→ 记录充电数据1
→ 记录充电数据2
→ 停止充电
→ 解锁充电枪
→ 拔枪并记录断开状态
→ 结束采集
```

一个Round只执行一次正常启动和一次正常停止。需要重新执行时创建新Round，不在同一Round中反复启停凑取结果。

## 3. VoiceRunner脚本Reference

```text
00s   开始采集
      立即启动CAN数据记录
      保持车辆无操作，拍摄未连接初始状态
      前往充电口准备取枪

40s   开充电小门
      正常打开充电口盖，暂不插枪

60s   插枪
      插枪到位后暂不扫码
      插枪异常时暂停并记录，不反复拔插

100s  记录连接状态
      进入驾驶舱，拍摄车辆端已连接但尚未充电的页面
      车辆未识别连接时暂停并记录，不继续扫码

160s  扫码启动
      前往充电桩，使用微信扫码启动充电
      充电开始且桩屏仍亮时，拍摄电压、电流和功率
      登录、授权或付款耗时较长时暂停，不追赶计划时间
      启动失败时暂停并记录页面提示

240s  记录充电数据1
      进入驾驶舱，拍摄车辆端当前充电页面
      随即保存微信小程序当前充电页面
      确保充电状态、功率、SOC及小程序电压、电流、功率清晰可见
      小程序未显示更新时间时，备注“实时性未知”
      尚未开始充电时暂停并记录页面提示

320s  记录充电数据2
      再次拍摄车辆端当前充电页面
      随即再次保存微信小程序当前充电页面
      确保充电状态、功率、SOC及小程序电压、电流、功率清晰可见
      小程序未显示更新时间时，备注“实时性未知”

380s  停止充电
      通过车机屏幕正常停止充电
      拍摄停止后仍连接的车辆端页面
      停止失败时暂停并记录页面提示

440s  解锁充电枪
      使用现场正常方式解锁充电枪
      已经自动解锁时确认释放，不重复操作
      无法解锁时暂停，不强行操作

470s  拔枪
      确认充电枪已经释放后拔枪
      未释放时暂停，不强行拔枪
      拔枪后进入驾驶舱，拍摄车辆端未连接、未充电页面

540s  结束采集
      停止CAN数据记录并保存ASC
      结束VoiceRunner本轮并保存全部现场记录
```

## 4. Reference检查点

- Event第一行是唯一播报内容，标题简短、清晰并可直接执行；其余行只作现场说明。
- VoiceRunner自动倒数并以提示音给出动作时间锚点，Script不重复写入倒计时。
- Event间隔覆盖系统响应、人员移动、设备切换、取证及下一次倒计时前就位所需时间。
- 插枪与连接取证、启动与两次充电取证、停止与解锁及断开保持连续关系。
- 两次充电数据Event分别形成建立后与稳定后的车侧、桩侧联合观察；小程序实时性未知时不作精确同步解释。
- 停止、解锁和拔枪保持为不同现场动作，安全条件不被压缩掉。
- 只明确要求FullCycle必要且现场自然可得的信息；页面自然带出的其他信息可以保留，但不增加操作要求。
- 脚本不包含Candidate Signal、DBC字段、不可见内部状态或未由本次现场条件提供的具体采集实现。
- 本Reference用于校验共享实现输出规格和现场风格，不反向定义Case、ER或OR。
