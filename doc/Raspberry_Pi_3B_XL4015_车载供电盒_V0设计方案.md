# Raspberry Pi 3B 车载点烟器供电盒 V0 设计方案

## 1. 目的

为 Raspberry Pi 3 Model B + USBcan-II
等轻量采集外设提供一套低成本、易制作、易替换的车载供电方案。

本方案以现有 Raspberry Pi 3B 原配电源参数 **5.1V / 2.5A**
为基准，使用车辆 12V 点烟器作为输入，通过 XL4015 可调降压模块转换为约
5.1V，为树莓派稳定供电。

设计定位：

-   单台自用、现场数据采集；
-   优先满足"好用、够用、稳定、便宜"；
-   尽量采用成熟现成模块，不自行开发复杂开关电源；
-   接口简单，方便装入小盒；
-   后续若产品化，可在本方案基础上增加更完整的汽车电源保护和 EMC 设计。

------------------------------------------------------------------------

## 2. 使用对象

### 主机

-   Raspberry Pi 3 Model B Rev 1.2
-   原配电源：+5.1V / 2.5A
-   电源接口：Micro-USB

### 主要外设

-   USBcan-II 双通道 CAN 卡
-   后续可挂接少量 USB 采集/通信设备

本方案不是为大功率 USB 外设、硬盘阵列等负载设计。

------------------------------------------------------------------------

## 3. 目标工况

  项目                 目标
  -------------------- -----------------------------------------------
  输入来源             汽车 12V 点烟器
  标称输入             约 12V
  DC-DC 模块输入能力   XL4015 模块常见宽压输入范围可覆盖汽车 12V系统
  输出电压             5.10V 左右
  推荐调整范围         5.10～5.15V，首次建议 5.10V

  设计重点             Pi 端不出现低压/馈电告警
  成本目标             电源主体及接口约几十元人民币

## 4. 核心设计原则

### 4.1 不依赖车辆 USB 口

笔记本 USB、普通充电宝以及部分车载 USB 口虽然标称
5V，但实际可提供电流、输出电压和线损条件不同，不能保证复制 Raspberry Pi
原配 **5.1V / 2.5A** 的供电条件。

因此车载使用时直接取：

**车辆点烟器 12V → 自有 DC-DC → Pi**

这样电源能力由自己的盒子控制，不依赖不同车辆 USB 口的规格。

### 4.2 XL4015 只负责核心降压

XL4015 是本方案的核心：

**12V → 约 5.1V**

选择可调输出版本，利用模块自带电位器设定输出电压，无需另做 5.1V
稳压电路。

### 4.3 不追求 XL4015 的 5A 极限

5A 是模块/芯片能力等级，不是本项目的实际目标负载。

本方案的设计思想是：

**让一个有较大余量的模块，轻松承担 Pi 3B + USBcan-II 的负载。**

这样比选择刚好卡在 2.5A 边缘的廉价电源更稳妥。

### 4.4 V0 不做"汽车 ECU 级"复杂化

当前目标是自己的现场采集盒，不是量产汽车电子控制器。

因此 V0 不额外堆叠：

-   独立 TVS 板；
-   独立反接保护板；
-   独立 LC/π EMI 滤波板；
-   复杂电源管理 MCU；
-   UPS/自动安全关机系统。

点烟器插头建议自带保险丝。

后续若进入客户长期安装、批量使用或更严苛汽车环境，再升级完整车载保护前端。

------------------------------------------------------------------------

## 5. 工作原理

车辆点烟器提供约 12V 电源。

12V 经点烟器插头进入供电盒，XL4015
采用开关降压方式将较高的直流输入转换为稳定的约 5.1V 输出。

输出通过短、粗、低压降的 Micro-USB 电源线进入 Raspberry Pi 3B。

之所以设定约 5.1V，而不是简单追求
5.0V，是为了接近树莓派原配电源的实际设计条件，并为输出接点、Micro-USB
插头及线材造成的少量压降留出余量。

首次调试必须在 **不连接 Raspberry Pi** 的情况下，用万用表测量 XL4015
输出并调整电位器。

## 7. 盒子内部电气连接

``` text
点烟器 +
   │
   └──────────────→ XL4015 IN+

点烟器 -
   │
   └──────────────→ XL4015 IN-

XL4015 OUT+
   │
   └──────────────→ Micro-USB +5V

XL4015 OUT-
   │
   └──────────────→ Micro-USB GND
```

如果直接使用剪开的 Micro-USB 电源线：

``` text
XL4015 OUT+ ───── 红色电源线 ───── Micro-USB → Pi

XL4015 OUT- ───── 黑色地线   ───── Micro-USB → Pi
```

若线材同时含白/绿数据线，本方案不使用数据线，应分别绝缘处理，不能与电源线短接。

## 8. 盒体建议

盒子的任务不是复杂，而是：

-   固定 XL4015，避免车内振动造成短路；
-   隔离裸露焊点；
-   给输入线和输出线提供应力释放；
-   给 XL4015 留出基本散热空间；
-   方便以后打开调整或维修。

推荐结构：

``` text
┌─────────────────────────────────┐
│          小型塑料盒             │
│                                 │
│  12V输入                        │
│    │                            │
│    ▼                            │
│ [接线固定]                      │
│    │                            │
│    ▼                            │
│ ┌─────────────────────┐         │
│ │ XL4015 + 散热片      │         │
│ │                     │         │
│ │ 调压电位器可维护     │         │
│ └─────────────────────┘         │
│    │                            │
│    ▼                            │
│ [输出线固定/应力释放]            │
│    │                            │
└────┼────────────────────────────┘
     │
     └──→ 短粗 Micro-USB → Pi 3B
```

不建议把 XL4015
完全密封灌胶，因为当前版本需要验证温升，并保留调压和维修能力。

## 10. 初次调试流程

### Step 1：只接 12V 输入

不要连接 Raspberry Pi。

``` text
12V电源
   ↓
XL4015
   ↓
万用表
```

### Step 2：测量输出

万用表置直流电压档：

-   红表笔：OUT+
-   黑表笔：OUT-

### Step 3：调整电位器

缓慢调整 XL4015 板上的多圈电位器。

目标：

**约 5.10V**

可接受的初始调整目标：

**5.10～5.15V**

不要为了补偿未知线损而随意把输出继续调高。

### Step 4：断电后连接 Pi

``` text
断电
 ↓
连接 Micro-USB
 ↓
连接 Pi 3B
 ↓
重新上电
```

### Step 5：实际负载验证

连接：

-   Raspberry Pi 3B
-   USBcan-II
-   实际 CAN 采集程序

连续运行，确认：

1.  Pi 正常启动；
2.  USBcan-II 工作稳定；
3.  无低压/馈电告警；
4.  XL4015 无异常高温；
5.  接头、线材无明显发热；
6.  长时间采集不重启、不掉 USB。

------------------------------------------------------------------------

## 11. 验证重点

不要只验证"Pi 能开机"。

真正的通过条件是：

``` text
能够开机
   ↓
USBcan-II 正常识别
   ↓
CAN 双通道实际工作
   ↓
Python/采集程序持续运行
   ↓
长时间数据采集
   ↓
无 Undervoltage
   ↓
无异常重启
   ↓
无 USB 掉线
   ↓
模块温升可接受
   ↓
V0 供电方案通过
```

建议至少进行一次数小时连续采集测试。

## 12. V0 与未来版本的边界

### V0 ------ 当前方案

``` text
点烟器
   ↓
保险
   ↓
XL4015
   ↓
5.1V
   ↓
Pi 3B
```

目标：

**自己的 Model 3 数据采集盒先稳定工作。**

### V1 ------ 后续工程化

若以后设备交给客户长期使用，可升级为：

``` text
车辆 12V
   │
   ▼
保险
   │
   ▼
反接保护
   │
   ▼
TVS / 汽车瞬态保护
   │
   ▼
EMI / 输入滤波
   │
   ▼
车载级 DC-DC
   │
   ▼
5.1V 稳定输出
   │
   ▼
Pi / 诊断采集主机
```

还可根据实际需要进一步考虑：

-   点烟器断电后的安全关机；
-   输入欠压/过压保护；
-   电源状态检测；
-   EMC；
-   汽车瞬态环境；
-   更可靠的锁止型连接器；
-   PCB一体化；
-   外壳阻燃和散热；
-   长期车内高低温环境。

这些属于下一阶段，不应成为 V0 上车验证的前置条件。

## 13. 给制作者的简版任务书

> 做一个小型车载电源盒。
>
> 输入为汽车点烟器约 12V，输出用于 Raspberry Pi 3 Model B。
>
> 树莓派原配电源为 5.1V / 2.5A，目前主要挂 USBcan-II 进行 CAN 数据采集。
>
> 核心采用成熟 XL4015 可调降压模块，输出调整到约 5.10V。
>
> 输入采用带保险的点烟器插头，输出使用短粗 Micro-USB 电源线。
>
> XL4015 放入小型绝缘盒内，需要固定、防短路、基本散热和线缆应力释放。
>
> 第一版目标不是汽车 ECU
> 级设计，而是低成本、稳定、容易维修的自用采集电源。
>
> 完成后需要在 Pi 3B + USBcan-II
> 实际连续采集负载下验证低压告警、USB稳定性、模块温升和长时间运行稳定性。

------------------------------------------------------------------------

## 14. 一句话定义

**这是一个把任何具备 12V 点烟器接口的车辆，转换成 Raspberry Pi 3B 稳定
5.1V 现场供电源的小型通用车载电源盒。**

它解决的不是"给树莓派找一根更好的 USB
线"，而是让诊断采集设备拥有自己可控、可验证、可复制的车载供电入口。
