# 伯恩盲态慢充自我训练—调查纸片

## 任务

在不读取DBC、Yi点位表、既有Signal结论和历史ASC Payload的条件下，仅使用慢充L3系统认知、S0009现场Event/图片与最新ASC，独立反推field-level候选。

## 用途

`SELF_TRAINING / BASELINE_SEMANTIC_DISCOVERY`，不对车辆作故障或健康判定。

## 盲态边界

- 允许：`event_timeline.csv`、`session.json`、现场图片、S0009原始ASC、本地L3交流慢充知识。
- 只允许从其他历史采集获得目录级“存在性”，不读取其ASC Payload。
- 禁止：任何DBC、Yi Round 1/2点位表、既有Signal映射、历史分析报告与Golden答案。
- 本轮结束前不用DBC评分；评分应作为另一个后续镜像阶段。

## L3空白地图

```text
充电口开启
→ 物理连接/CC-CP识别
→ 锁止与已连接未充电
→ 启动请求、许可与Vehicle Ready
→ 交流输入/OBC执行/高压与Pack响应
→ 稳态充电
→ 停止但仍连接
→ 解锁但仍连接
→ 拔枪恢复
```

## 第一轮主要辨识问题

1. 哪些field跟随充电口开启周期？
2. 哪些field跟随物理连接周期，且可与“正在充电”分离？
3. 哪些field仅在充电执行窗口成立？
4. 哪些field在停止后仍保持，直到拔枪才恢复？
5. 哪些连续量在充电建立和停止两个边沿都有响应？

## 已知限制

- `E05`是扫码动作，不是精确的功率建立时刻；需从CAN中找候选转移，但不得倒推为人工Event时间。
- 两段ASC的第二段从13:44:50开始，需按绝对时钟折算到同一时间轴。
- 单轮同步变化仍可能是共同原因；本轮只能得到角色候选和概率，不得虚构官方Signal名称。
