# 班吉（CANVoiceRunner）独立项目迁移备忘

**状态：** `BACKLOG / APPROVED / 未启动`  
**记录日期：** 2026-09-14  
**性质：** 待做任务备忘；本文不授权立即迁移、删除旧目录或调整接口。

## 目标

将当前位于 `android/CANVoiceRunner/` 的班吉（CANVoiceRunner）Android 工程，在合适时机迁移为与 TeslaCanPython 并列的独立项目，使其能够独立开发、测试和发布，同时保持 TeslaCanPython 对采集脚本、Round、Event及Evidence的稳定追溯。

## 职责边界

班吉独立项目负责：Android App、现场播报与倒计时、Event实际时间、照片、Note、录音、结构化导出、App输入/输出合同及版本发布。

TeslaCanPython继续负责：L3 Case、ER/OR、Acquisition Plan、班吉脚本Renderer、Vehicle与Round规则、Acquisition Package、Validation、Recognition、CAN/Signal/Evidence分析及报告裁决。

## 迁移前提

1. 冻结班吉当前可用版本及Script、`session.json`、`event_timeline.csv`合同。
2. 明确班吉仓库中的权威合同与TeslaCanPython所支持合同快照之间的版本和哈希关系。
3. 盘点并更新TeslaCanPython中指向`android/CANVoiceRunner/`的有效引用。
4. 设计保留Git历史的迁移方式，并为原目录准备可回退方案。
5. 迁移后同时通过班吉Android测试及TeslaCanPython的Acquisition Plan、Validation和Recognition相关测试。

## 约束

- 不把Acquisition Plan、Case契约或分析流程搬入班吉。
- 不让TeslaCanPython依赖另一工作目录中的不稳定相对路径。
- 不建立两套人工维护的接口合同真值。
- 不借迁移顺带重构App、扩展Schema、改名包名或开发新功能。
- 未收到导演明确启动指令前，不执行迁移。

## 建议启动时机

在当前伯恩Round 4、罗格实车采集闭环等眼前任务不受影响，且班吉没有正在进行的现场采集或版本改动时，再单独启动本任务。
