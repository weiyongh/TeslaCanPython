# 实车采集前文档体系与分析接口

**状态：** 项目当前有效  
**生效日期：** 2026-09-01

> 实车诊断实验的数据质量，从采集前的证据设计开始。

## 1. 每次实验固定文件

采集前统一生成三份文件：

1. `TM3-xxx_实验采集方案.md`：解释为什么采、验证什么、证据从哪里来、怎样判定有效和完成。
2. `TM3-xxx_语音执行脚本.txt`：只指导现场现在做什么，保持简短并可直接TTS。
3. `TM3-xxx_现场采集记录.md`：在采集前生成空白模板，记录现场实际发生的事件、外部证据和偏差。

模板位于`doc/templates/experiment_collection/`。方案完整、脚本简单、记录明确、现场Checklist最短可执行。

## 2. 证据来源设计

每个核心实验问题在方案中按以下接口设计：

`实验问题 → 车内CAN证据 → SMT/诊断工具证据 → 人工事件证据 → 外部物理证据`

不要求所有问题都有四类证据；凡结论跨越车辆系统边界，必须主动寻找边界外证据。若某类证据不需要，方案必须说明理由，而不是留空后默认不采。

上一实验的Evidence Gap和Signal Validation缺口应前移为下一实验的Evidence Requirement、现场记录字段和结束前Checklist项。例如`CP_evseOutputDcCurrent=TIMING_ONLY_VALID`应自动要求同步取得桩端DC V/I/P。

## 3. 三种时间的正式接口

后续分析必须分别读取并保存：

- `Planned Time`：TTS计划相对时间，只用于现场导航；
- `Observed Event Time`：人工口述、录音、视频、设备日志或外部记录提供的实际事件时间；
- `CAN Observed Time`：ASC中Signal或状态变化时间。

三者不得互相替代。允许分析`Observed Event Time → CAN Observed Time`，禁止用CAN变化反推人工操作时刻，再用该反推时刻证明CAN响应正常。实际事件没有独立锚点时，必须标记缺口。

推荐后续机器接口字段：

`event_id / planned_time / observed_time / observed_time_source / action / external_observation / evidence_file / deviation / can_observed_time / can_basis`

现场记录只填写至`deviation`；CAN时间及判据由分析阶段追加到独立附件，不回写伪造现场事实。

## 4. 完整性与完成状态

现场记录必须包含开始前、结束前Checklist以及实验专用检查项。结束前检查在人仍位于车辆、道路、充电桩或设备现场时完成。

完成状态由Evidence Requirements满足程度决定：

- `COMPLETE`：核心车内证据、实际事件锚点和必要外部证据完整；
- `COMPLETE_WITH_GAPS`：主体实验有效，存在不影响核心判断的非关键缺口；
- `PARTIAL`：只能建立部分基线或回答部分问题；
- `INVALID`：核心实验状态、动作或有效窗口未成立；
- `ABORTED`：因安全、环境或操作原因主动终止。

单个Signal缺失不自动导致INVALID；仅存在ASC文件也不自动等于COMPLETE。现场可先给出`PROVISIONAL`状态，分析后依据Evidence Assessment确认最终状态。

## 5. Signal Validation前移

P0/P1 Signal若为`PARTIALLY_VALIDATED / TIMING_ONLY_VALID / QUANTITATIVE_SEMANTICS_UNVALIDATED`或存在DBC冲突，采集方案必须增加“独立验证证据”栏，并同步生成：

- 现场记录填写项；
- 对应计划动作或机会窗口；
- 结束前专用Checklist；
- 最小文件命名与时间锚点要求。

不得要求现场人工抄录本可由ASC/SMT自动保存的大量Signal数值。现场只记录动作、条件、外部读数、证据文件和偏差。

## 6. 安全与偏差

计划时间不是安全命令。无法按名义秒数发生的事件应使用条件式指令，例如“桩显示开始输出后”。安全、道路、场站或设备条件优先于TTS。偏差不自动等于失败；未记录的偏差会污染分析。

## 7. TM3-015反向验证结论

样例位于`doc/examples/TM3-015_采集前文档回归样例/`。新体系把桩端V/I/P、订单、实际停止、解锁和拔枪时间分别放入：

1. 方案的必要Evidence Requirement；
2. TTS的条件式拍摄/口述提示；
3. 现场记录的专用字段；
4. 结束前专用Checklist。

因此在离开充电桩前可以明确发现证据遗漏，解决TM3-015暴露的外部能源证据缺口。该样例不修改历史实验事实或Golden分析结果。
