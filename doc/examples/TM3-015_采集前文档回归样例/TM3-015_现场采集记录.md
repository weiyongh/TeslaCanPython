# TM3-015 直流快充现场采集记录（采集前空白样例）

计划时间只用于导航。实际时间必须来自口述录音、视频、照片、桩/App记录或其他独立时间锚点。

## 开始前检查

- [ ] X930正常，只监听，全量ASC存储空间充足
- [ ] CAN通道、波特率和记录时钟确认
- [ ] SMT/辅助工具准备完成，或记录本次不使用
- [ ] TTS脚本试播正常
- [ ] 手机/相机有空间、电量，照片保留原始时间
- [ ] 车辆P挡、已唤醒、未插枪
- [ ] 初始SOC、Pack温度、软件版本、HVAC和预热状态已记录
- [ ] 桩运营商、型号、编号、额定功率和共享情况已记录
- [ ] 充电上限和预约状态已记录
- [ ] ASC、TTS、录音/视频和桩/App时钟已对时
- [ ] **已确认能够拍到桩屏DC Voltage / Current / Power**
- [ ] **已确认充电结束后能够保存订单/累计电量**
