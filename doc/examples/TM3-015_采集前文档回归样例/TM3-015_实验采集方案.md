# TM3-015 直流快充实验采集方案（采集前回归样例）

**实验编号：** TM3-015  
**用途：** 正常基线采集  
**车辆：** 上海产2021款Model 3，2021年5月，标准续航55 kWh，后驱  
**样例性质：** 假设实验尚未执行，用于验证新采集前文档体系；不修改历史实验事实

## 1. 实验目的

观察直流快充从连接、车辆可见准备、高压直流建立、电流建立、短稳态、主动停止到连接释放的车辆侧响应，建立条件化时序基线，并取得与车辆CAN不同来源的桩端能源证据，用于核查CP/Pack电压、电流和功率的定量一致性。

不追求峰值功率、全SOC曲线、充满降流、容量/SOH、完整协议逆向或热管理闭环。

## 2. L3控制关系与系统边界

车辆侧主链：

`连接检测/锁止 → 可见通信/协商 → 整车状态 + 电池状态 + 安全条件 → 车辆充电条件判断/许可 → 高压直流充电状态 → 直流电流建立 → 主动停止 → 电流退出 → 连接释放`

- 边界内：车辆充电口控制、BMS、高压接触器、Pack能源响应及可见状态。
- 边界外：扫码、付款、运营商平台、充电桩内部控制、桩端计量和人工动作。
- 主验证线：车辆侧状态、请求/条件候选、高压执行和电流建立/退出。
- 能源交叉线：桩端V/I/P ↔ CP候选V/I ↔ Pack V/I及V×I ↔ SOC/累计量。
- 热管理仅记录条件和过程，不作为本次完整控制闭环目标。

## 3. 状态与Evidence Requirements

状态转换：`未连接 → 已连接/锁止 → 等待授权/准备 → 电压建立 → 电流建立 → 短稳态 → 停止中 → 输出退出 → 解锁/拔枪`

| ER | 要证明的事实/关系 | 满足判据 | 关键性 | 缺失影响 |
| --- | --- | --- | --- | --- |
| ER-01 | 开盖、插枪、锁止和连接释放具有独立实际事件锚点 | 口述/视频时间与CAN边沿均保存 | 核心时序 | 缺失则只能按CAN候选重建，不能计算人工动作响应 |
| ER-02 | 外部授权后车辆进入可见准备/充电阶段 | 扫码、提交、桩接受分别记录，车辆状态随后变化 | 核心时序 | 不能还原外部事件到车辆响应关系 |
| ER-03 | 高压状态建立后直流电流建立 | 接触器/充电状态候选、电压、电流顺序一致 | 核心 | 无法形成充电建立链 |
| ER-04 | Pack侧与桩端能源数量级一致 | 同一稳定窗口具备桩端V/I/P、Pack V/I和累计量 | 核心定量 | 只能建立方向/时序，不能标定桩端电流或效率 |
| ER-05 | 获得至少20–30 s短稳态 | 车辆及桩功率相对稳定，设置不变 | 核心基线 | 仅保存爬升过程 |
| ER-06 | 主动停止后输出退出 | 停止入口、确认、电流归零、解锁分别有实际锚点 | 核心时序 | 停止请求与执行不能分层 |
| ER-07 | 实验条件与偏差可追溯 | SOC、温度、HVAC、桩信息、重试和漏项记录 | 辅助 | 限制基线外推 |

| 连接与锁止何时发生 | CP/VCSEC/HVP连接锁止候选 | 可见充电口状态 | 开盖、插枪、锁止口述/视频 | 枪实际插入与锁止观察 | 实际插枪和拔枪时间必取 |
| 授权后何时进入车辆准备 | BMS/CP/FC阶段候选 | 车辆充电状态页面 | 扫码完成、提交启动、桩接受口述 | App/桩屏接受状态 | 三个事件能区分则必取 |
| 何时建立直流充电 | 接触器、电压、电流、Pack电流 | Pack V/I、充电状态 | 口述“桩已开始输出” | **桩屏DC V/I/P照片或视频** | **必取** |
| 稳定段定量是否闭合 | CP V/I候选、Pack V/I、累计量 | SMT Pack V/I/P | 稳定段开始/结束口述 | **稳定段桩屏V/I/P和累计电量** | **必取** |

| 总能源是否闭合 | Pack累计量/SOC候选 | SMT累计量（如有） | 结束事件 | **订单电量、时长、结算截图** | **必取** |

## 5. 核心Signal与Signal Validation前移

| Signal | 中文语义 | 角色/P等级 | 采集前成熟度边界 | 本次独立验证证据 |
| --- | --- | --- | --- | --- |
| `BMS_packCurrent (0x132)` | Pack净电流 | 能源Actual / P0 | DBC符号/位宽存在来源差异 | 同帧冗余电流、Pack V×I、累计量、桩端功率 |
| `CP_evseOutputDcCurrent (0x29D)` | EVSE输出电流候选 | 执行反馈 / P0 | 定量语义待独立标定 | **同一稳定窗口桩屏DC Current/Power** |
| `CP_evseOutputDcVoltage (0x29D)` | EVSE输出电压候选 | 能源交叉 / P1 | 候选 | 桩屏DC Voltage、Pack Voltage |
| `BMS_chgPowerAvailable (0x212)` | BMS可用充电能力候选 | Available / P1 | DBC位段冲突；非Request/Actual | 非充电SNA、爬升、稳定Actual及跨SOC变化 |
| 连接/锁止/充电阶段候选 | 车辆连接和阶段状态 | 状态链 / P0-P1 | 候选不得按名称直接确认 | 实际插枪、锁止、停止、解锁和拔枪时间 |

## 6. 数据源、条件与文件

- X930：全量ASC，只监听；采集前确认通道、波特率、存储空间和时钟。
- SMT：可选辅助；提前开始，不能因接线影响X930。
- 手机/相机：用于口述录音、关键桩屏照片/视频、订单截图；照片需保留原始时间。
- 对时：记录ASC零点、TTS零点、手机录像起点和桩/App时间；结束时复核一次。
- 计划文件：`TM3-015_直流快充_YYYYMMDD_HHMMSS_R1.asc`及同前缀照片、视频、SMT和订单文件。

前置条件：P挡、车辆唤醒、未插枪、预约不阻止即时充电、SOC有合理充电空间；记录软件版本、SOC、Pack温度、环境温度、充电上限、预热/行驶、HVAC、桩运营商/型号/编号/额定功率/共享情况。

## 7. 操作步骤

| 计划时间/条件 | 操作 | 口述/外部证据 | 顺延规则 |
| --- | --- | --- | --- |
| 0 s | 开始ASC、SMT和录音，保持未插枪背景 | 口述“采集开始” | 未确认设备正常不进入下一步 |
| 20 s | 打开充电口盖 | 口述“充电口已打开” | 记录实际时间，不追赶计划 |
| 40 s | 插枪到位 | 口述“插枪完成”；观察锁止 | 按桩要求可调整扫码顺序 |
| 60 s后 | 按桩流程扫码、授权、启动 | 分别口述“扫码完成”“启动已提交”“桩已接受” | 网络延迟时按实际流程，不制造名义事件 |
| 桩显示开始输出后 | 不改变设置，观察建立过程 | 口述“充电开始”；**拍摄桩屏DC V/I/P** | 未输出不得口述充电开始 |
| 输出相对稳定后 | 保持至少20–30 s | 口述“稳定段开始”；拍摄桩屏V/I/P和累计量；结束时再口述 | 不能稳定则保存爬升过程并记录 |
| 计划240 s或提前决定停止时 | 从正常入口申请停止一次 | 口述停止入口和“停止已提交” | 不用急停模拟普通停止 |
| 桩/车确认输出归零后 | 等待正常解锁，再拔枪 | 拍摄归零画面；口述“停充确认”“解锁”“拔枪” | 未解锁不强拔 |
| 拔枪后约30 s | 保存数据并做离场Checklist | **保存订单/结算/累计电量截图** | Checklist未完成时先补证据或记录缺口 |

## 8. 窗口、无效、终止与安全

- 有效建立窗口：实际插枪/授权前背景完整，随后观察到车辆充电状态、电压和电流建立。
- 有效稳态窗口：实际输出建立后，设置不变且桩/Pack量连续20–30 s相对稳定。
- INVALID：没有形成实际直流输出，或ASC关键建立/停止段丢失。
- PARTIAL而非INVALID：已形成充电和时序，但桩屏/订单漏取或稳态不足。
- ABORTED：高压/过热告警、线缆破损、焦味、异常发热、场站要求、设备接线风险或其他安全原因。
- 仅在正常停充、输出归零、锁止释放后拔枪；不把急停或应急拉索作为实验动作。

## 9. 采集完成判定

| 状态 | TM3-015具体判据 |
| --- | --- |
| COMPLETE | ASC覆盖背景—建立—稳态—停止—释放；关键事件有独立锚点；稳定段桩屏V/I/P和订单完整 |
| COMPLETE_WITH_GAPS | 核心链、稳态、停止及能源外证据完整，仅缺不影响核心问题的辅助条件 |
| PARTIAL | 充电主体有效，但缺稳定段、关键外部能源证据或释放事件锚点，只能建立部分基线 |
| INVALID | 未形成直流充电或关键ASC段不可用 |
| ABORTED | 因安全、环境或操作原因主动终止 |

离开桩前核心标准：ASC已保存；插枪、充电开始、停止、解锁、拔枪有实际时间锚点；**桩端V/I/P照片和订单已取得**；偏差已记录。
