# TM3-017 现场采集记录

**实验名称：** 交流慢充电流控制阶跃

计划时间只用于导航；实际事件时间必须来自VoiceRunner、照片、录音、视频或设备记录。不得根据ASC变化反填人工动作时间。

## 开始前检查

- [ ] Vehicle Marker计划使用`TESLA-M3-SOP5`
- [ ] ASC设备正常并确认全量监听配置
- [ ] VoiceRunner已载入`TM3-017_语音执行脚本.txt`
- [ ] 相机及桩屏或配套应用已经准备
- [ ] 车辆P挡，交流慢充正在持续进行
- [ ] 车辆电流设置为32 A
- [ ] 实际交流电流接近32 A并稳定至少30秒；或已记录V/P及估算边界
- [ ] 已确认充电过程中可以直接执行32→16→32 A，不需停充或重连
- [ ] 16 A处于允许设置范围
- [ ] HVAC、充电上限、预约及其他人工设置已记录并将在Round内保持不变
- [ ] 车辆、充电设施无告警或明显安全风险
- [ ] 若任一核心前置条件不满足，本轮不开始
