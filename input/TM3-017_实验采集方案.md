# TM3-017 实验采集方案

**实验编号：** TM3-017  
**实验名称：** 交流慢充电流控制阶跃  
**Case：** `L3-Charge-Slow-CurrentControl`  
**用途：** 正常基线  
**方案版本/日期：** v0.2 / 2026-09-15  
**状态：** 已审核通过  
**车辆范围：** `TESLA-M3-SOP5`

## 1. 实验目的与控制关系

**实验目的：** 在同一连续交流慢充过程中，将车辆可调充电电流设置由32 A调低到16 A并恢复到32 A，验证设置被接受后，实际交流取电是否产生方向一致、时间对应且能够形成稳定窗口的下降与恢复。

**要验证的L3控制关系：**

```text
操作者充电电流设置
→ 设置被车辆接受并保持
→ 实际交流电流/功率经过响应时间下降或恢复
→ 新设置下形成连续稳定充电窗口
```

操作者设置是外部可控输入，不等同于车辆内部允许能力、内部目标或桩侧允许电流。实际交流取电是本实验核心反馈；Pack侧响应仅为可选增强证据。

**不在本次范围：** 完整慢充生命周期、预约充电、桩侧主动限流、热降额、SOC降额、异常限流、停止/重启充电、连接与锁止语义、具体CAN字段命名、DBC验证和故障诊断。

## 2. 系统边界与主线

- 系统/子系统：交流慢充电流控制。
- 边界内：车辆对充电电流设置的接受、持续充电状态及实际交流取电响应。
- 边界外输入：操作者在车辆端执行的32 A、16 A、32 A设置动作；EVSE当前可用能力。
- 边界外输出/物理证据：车辆页面、桩屏或配套应用显示的实际交流电流与功率。
- 主验证线：`32 A设置 → 16 A设置 → 实际取电下降 → 16 A稳定 → 恢复32 A → 实际取电上升 → 32 A重新稳定`。
- 交叉验证线：车辆与桩端/配套应用在相邻时间取得的状态、电流和功率；ASC中的原始变化只在采后分析阶段评价。

### 2.3 预期Tree Delta

完整取得预期Evidence且结果方向一致时，本轮拟对车型投射控制树增加以下条件化分支：

```text
前置门：连接保持 + 正常充电已稳定 + EVSE能力足以维持初始约32 A
                       + 无已观察到的停充、重连或人工条件变化
                              ↓
操作者充电电流设置：32 A → 16 A → 32 A
                              ↓
车辆界面接受并保持设置
                              ↓
[内部Target / 能力 / 仲裁：保留为未直接观察节点]
                              ↓
实际交流取电：高 → 低 → 恢复高
                              ↓
三个连续、非瞬态稳定窗口
                              ↓
[OBC / Pack下游响应：仅在独立Evidence存在时增强]
```

按结果形成不同Delta：

- **预期闭环完整：** 新增并支持`操作者设置→设置被接受→实际交流取电方向一致且可逆`；保留内部仲裁节点为空缺。
- **设置接受但实际响应不变：** 只确认N-CC-01和N-CC-02；R-CC-01记为`CONTRADICTED`或`INSUFFICIENT_EVIDENCE`，并优先检查EVSE能力、其他限制或外部显示实时性，不直接判车辆异常。
- **仅调低侧有效：** 保存调低侧过程基线，恢复关系仍为空缺；实验状态最多为`PARTIAL`。
- **发生停充、重启或重连：** 不新增稳态电流控制Relationship；相关数据仅作为过程Evidence。
- **CAN候选随阶跃响应：** 只新增行为分类和本实验角色候选，不升级为正式Signal语义。

6. 后续实验的选择依据：优先用可逆响应候选研究内部Target/Actual；固定车辆设置后改变EVSE能力研究外部能力仲裁；固定设置并延长充电研究热降额；在不同SOC重复相同阶跃研究SOC条件；独立重复同一阶跃验证候选重复性。

## 3. 前置条件与固定阶跃

本方案不把现场数值留到Event发生时临时决定。Round开始前必须全部满足：

1. 车辆P挡，交流慢充已经建立，车辆充电电流设置为32 A。
2. 车辆或桩端可见的实际交流电流在接近32 A的水平稳定至少30秒；若只能看到功率，必须同时取得电压并将电流标记为估算。
3. 车辆支持在持续充电过程中直接调整设置，不需要停止、重启或重新连接。
4. 16 A处于当前允许设置范围，并明显低于调整前实际充电水平。
5. 空调、充电上限、预约状态及其他可能改变充电功率的人工设置在Round内保持不变。
6. ASC与VoiceRunner、相机以及桩屏或配套应用已经准备好。

任一项不满足时不开始本Round；记录现场事实后重新提交方案，不临时改用其他阶跃。

## 4. 状态机与Evidence Requirements

**关键状态转换：**

```text
32 A稳定充电
→ 设置调低到16 A并被接受
→ 实际交流取电下降
→ 16 A稳定充电
→ 设置恢复到32 A并被接受
→ 实际交流取电上升
→ 32 A重新稳定充电
```

| ER | 要证明的事实/关系 | 满足判据 | 关键性 | 缺失影响 |
| --- | --- | --- | --- | --- |
| ER-01 | 初始控制基准成立 | 32 A设置、实际响应和连续稳定充电均有带时间证据 | 核心 | 无法建立调低前基准 |
| ER-02 | 有效调低输入成立 | 32→16 A动作有独立时间，16 A设置被接受并保持 | 核心 | 无法证明有效输入 |
| ER-03 | 调低响应成立 | 调低后实际交流电流或功率相对初始窗口明确下降，超过显示分辨率和初始波动 | 核心 | 无法回答下降响应 |
| ER-04 | 低设置状态保持 | 16 A设置下持续充电并形成至少30秒非瞬态窗口 | 核心 | 只能保留瞬态过程证据 |
| ER-05 | 恢复响应成立 | 16→32 A动作有独立时间，实际交流电流或功率相对低设置窗口明确上升 | 核心 | 无法回答恢复响应 |
| ER-06 | 恢复状态保持 | 恢复后形成至少30秒稳定窗口，三窗口间无停充、重启或重连 | 核心 | 无法形成同Round闭环 |

“明确变化”以直接显示值为优先：变化方向正确，且变化量大于显示分辨率及初始稳定窗口的正常波动。不得因为设置值改变就推定实际响应已经改变。

## 9. 窗口、无效和终止判据

**有效窗口判定：** 初始、低设置、恢复三个窗口各至少包含30秒连续、非瞬态、设置保持且正在充电的ASC；每个窗口至少有一组带时间的车辆设置/响应与桩端或应用实际响应记录。稳定起点按实测响应进入稳定状态确定，不使用计划秒数替代。

**实验无效条件：** 初始实际取电没有稳定建立；16 A未被接受；响应变化不具判别力；任意两窗口间发生停止、重启、重新连接；调整同时改变空调、充电上限或其他主要条件；关键动作没有独立实际时间；ASC未覆盖两次阶跃及三个窗口。

**主动终止条件：** 车辆或充电设施报警；充电异常退出；设置入口行为与预期明显不同；设备记录中断；现场安全或场站要求停止；枪线、接口或设备出现异常温升、异味、烟雾或其他风险。

**安全边界：** 不操作急停模拟正常控制；不拔枪；不改线；不绕过车辆或充电设施保护；安全和场站要求优先于计划时间。

## 10. 采集完成判定

| 状态 | 本实验具体判据 |
| --- | --- |
| COMPLETE | 六项ER均有核心证据，三窗口有效，两次相反阶跃和实际响应闭环成立 |
| COMPLETE_WITH_GAPS | 六项ER主体成立，仅缺可选Pack证据、非核心页面或精确刷新时间 |
| PARTIAL | 仅调低或恢复一侧形成有效响应，另一侧证据不足但已有窗口可独立保留 |
| INVALID | 有效阶跃、实际响应或同一连续充电过程等核心条件不成立 |
| ABORTED | 因安全、现场或设备原因主动终止，未完成核心序列 |

**核心完成标准：** `32 A稳定 → 16 A设置接受 → 实际响应下降并稳定 → 32 A设置恢复 → 实际响应上升并稳定`，全过程没有停止、重启或重连，且ASC、实际事件和外部证据可追溯。

**允许的非阻塞缺口：** Pack侧增强证据缺失；配套应用没有明确刷新时间但桩屏或车辆提供了足够实际响应；非核心SMT记录缺失。
