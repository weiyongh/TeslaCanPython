# 第三轮修订版：HVAC 五个同条件会话重复验证

## 本轮目标

使用 S0014–S0018 五份 `MinSingRound` 采集，验证第二轮单周期 HVAC raw bit 能否在五个单独采集会话中同条件复现，并从全总线重新筛选补充观察。第二轮产物保留在 `results/round_2/`，本轮没有覆盖或改写。本文件已按 `M_Round3_Pure_Audit.md` 修订。

## 与第二轮的区别

第二轮修复了分段 ASC 时间轴重建问题，并从一个长会话的一次 OFF→ON→OFF 中提出候选；证据的主要限制是只有一个周期。

第三轮把五个短会话视为五个单独采集会话中的同条件重复验证，不称为五种独立条件。raw bit 必须逐轮满足 OFF 前＝OFF 后且不同于 ON，不能依赖把五轮样本合并后的总体多数。随后再要求每轮全程只有开启和关闭两次翻转，以排除稳态窗口恰好一致但过程中反复变化的字段。

## 数据与时间窗

- 会话：S0014、S0015、S0016、S0017、S0018，均为 `COMPLETED`。
- 总帧数：2,592,668；每轮约 518k 帧。
- 每轮只有一个 ASC，内部时间戳单调，无无效帧行。
- ASC 文件头只有整秒精度。使用文件头墙钟减 `session.start_clock` 得到脚本时间偏移；因此稳态判断可靠，绝对响应延迟保守按约 ±1 s 时间对齐不确定度解释。
- OFF 前：E02 后 5 s 至 E03 前 5 s。
- ON：E04 至 E05 前 5 s。
- OFF 后：E06 至 E07 前 5 s。

上面三个窗口都来自各会话的实际事件时间，而不是固定套用名义 30/60/100/160/200/230 s。

## 已由当前数据证明的事实

第一层稳态筛选得到 52 个 bit：它们在 5/5 轮中方向一致，且每轮三个状态窗口的最低纯度不低于 95%。其中 47 个最低窗口纯度为 100%，其余 5 个为 95.24%–98.55%。

第二层全程翻转筛选得到 **23 个跨五轮复现的二态 raw bit**，分布在 10 个 CAN ID：

| CAN ID | 复现的 raw bit |
|---|---|
| `0x1FA` | `B0.b3`, `B0.b4` |
| `0x20C` | `B1.b3`, `B1.b4`, `B4.b1`, `B5.b0`, `B7.b3` |
| `0x253` | `B7.b4` |
| `0x282` | `B0.b2`, `B0.b6`, `B1.b2`, `B2.b1`, `B3.b3` |
| `0x2A1` | `B5.b0` |
| `0x2A7` | `B7.b0`, `B7.b2` |
| `0x2BF` | `B5.b3`, `B5.b4` |
| `0x2F3` | `B3.b2` |
| `0x323` | `B4.b1`, `B4.b2` |
| `0x361` | `B3.b1`, `B3.b2` |

“23 个 bit”不等于 23 个独立 Signal 或 23 条独立 Evidence。同一报文或同一字节中同步翻转的多个 bit 可能是一个枚举值、连续数值的量化位、派生状态或复制投影。

## 从 bit 回到待恢复字段组

将 23 个 raw bit 先按其所在的 CAN ID 与字节合并，得到 **16 个字节级待恢复字段组**。这只是字段边界假设，不是已经恢复出 16 个 Signal。

- 7 组包含多个 raw bit，9 组只有一个 raw bit。
- 所有组的候选掩码取值都在五轮中重复；例如 `0x1FA B0` 的候选掩码 `0x18` 呈 `0x00→0x18→0x00`。
- 部分组虽然候选掩码重复，但完整字节还含其他变化位；这类组不能把完整字节直接当作二态状态。
- 同字节成员也不一定同时翻转，例如 `0x20C B1`、`0x282 B0` 和 `0x2BF B5` 内的成员转换并非完全同步，说明字节级分组仍可能包含多个子字段或数值位。

完整分组与掩码见 `raw_field_groups.csv`。当前数据只能把 23 个 raw bit 收敛成 16 个待恢复字节组，不能进一步可靠确定跨字节字段边界。

## 响应顺序的有限解释

`0x1FA B0.b3`、`0x20C B1.b3` 和 `0x282 B0.b2` 与人工操作在当前约 ±1 s 对齐精度内近同时变化，组内亚秒先后无法可靠区分。`0x2A1 B5.b0` 和 `0x2BF B5.b3` 在开启侧平均位于数秒后，且多个单轮明显晚于近事件组，因此可以保留“存在相对较晚响应组”的粗粒度观察。

这不支持比较近事件组内部的亚秒先后，也不能据此把近事件组命名为请求、较晚组命名为压缩机反馈。明细表保留原始数值仅为可复核记录，不作为亚秒因果排序证据。

转换匹配现已显式记录 `before→after`，并要求开启附近方向与 OFF→ON 稳态方向一致、关闭附近方向相反。23 个复现 raw bit 的 115 组“会话×bit”记录全部通过方向核对。

## 照片核验

人工检查五轮 E03 和 E05 照片：E03 均显示 HVAC 面板打开，电源与 A/C 为蓝色、手动 23°C、风量 4；E05 均回到无 HVAC 面板的车辆页面。照片与脚本标注的 ON/OFF 方向一致。照片证明 UI 状态，不直接证明压缩机实际运行。

## 修订后的核心结论

第二轮五个优先 raw bit 均在 5/5 个单独同条件会话中呈现 OFF 前与 OFF 后一致、ON 期间相反，三个稳态窗口纯度均为 100%，且每轮只有一次开启方向翻转和一次关闭方向翻转。

全总线共有 52 个 raw bit 通过逐轮稳态筛选，其中 23 个还通过逐轮两次翻转及显式方向检查；它们可合并为 16 个字节级待恢复字段组。以上证明的是观察模式重复，不证明任何具体功能身份、独立 Signal 数量或精确响应时延。
