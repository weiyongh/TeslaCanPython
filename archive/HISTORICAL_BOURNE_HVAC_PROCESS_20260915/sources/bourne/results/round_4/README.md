# Round 4：HVAC 模式、风量与 A/C raw bit 响应分化

## 结论摘要

五个会话 S0019–S0023 均记录 E01–E13，每轮单段 ASC 的首末时间约为脚本时间 0–330 s，共解析 3,711,471 帧；未发现无法解析的数据样式行，未发现段内时间戳倒退（来源：`session_quality.csv`、`timeline_reconstruction.json`）。这些检查不等同于证明采集过程丢帧为零或段内不存在时间间隙。人工核对照片后，六个预注册状态与脚本一致；S0023 的第七张是 S3 的补拍，不改变事件或 CAN 窗口（来源：`photo_evidence_index.csv`）。

Round 3 的 23 个二态 raw bit 在 Round 4 被拆分为：

| 实验刺激标签 | raw bit 数 | 判别模式 |
|---|---:|---|
| HVAC/送风开启相关 | 9 | S0=S5，S1=S2=S3=S4，开启侧不同于关闭侧 |
| 风量变化敏感 | 5 | S1 不同于 S2，且 S2=S3=S4 |
| A/C UI 切换可逆相关 | 8 | 仅 S3 不同，S2=S4 |
| 本轮保持常值、未分类 | 1 | 六状态均为 0 |

上述类别名称均是本轮实验刺激标签，不是系统语义命名。对 16 个继承组重新评估后，13 组满足“全部成员同属一种刺激响应”的组级接受条件，其中 5 组为 HVAC/送风开启相关、4 组为风量敏感、4 组为 A/C UI 切换可逆相关；G02 与 G07 是复合响应组，不能接受单一组标签；G03 在六状态中保持常值（来源：`round3_group_summary.csv`、`round3_bit_disambiguation.csv`）。raw bit 层的 9/5/8/1 计数不变，不能与组级 5/4/4/2/1 计数互换。

## 字段级假设裁决

`field_level_hypotheses.csv` 对每个继承组给出本轮存废状态，共 18 个候选分区：

- G02 拆为 `B1.b3`（A/C UI 切换相关）与 `B1.b4`（HVAC/送风开启相关）；G07 拆为 `B0.b2`（HVAC/送风开启相关）与 `B0.b6`（风量 2→6 敏感）。两组原掩码均被否定为单一响应整体。
- G03 因五轮六状态均为常值而暂停，现有数据不支持刺激相关字段假设。
- 8 个单 bit 组保留单 bit 候选分区，但不能排除它们属于未纳入边界的更宽字段。
- G01、G12、G13、G15、G16 的组内成员同步或互补，保留原候选边界但不合并为已确认字段。一个多 bit 枚举、多个同步/互补 flag、复制值或派生值仍都与现有 Evidence 相容。

因此，本轮形成的是可审核的 field-level hypothesis 集合，不是已解码字段清单。同步 raw bit 不因轨迹一致而自动合并。

## Round 3 候选的六状态结果

### HVAC/送风开启相关

- `0x1FA B0.b3`, `0x1FA B0.b4`
- `0x20C B1.b4`
- `0x253 B7.b4`（反方向）
- `0x282 B0.b2`, `0x282 B1.b2`
- `0x2F3 B3.b2`
- `0x323 B4.b1`（反方向）, `0x323 B4.b2`

### 风量变化敏感

- `0x20C B5.b0`, `0x20C B7.b3`
- `0x282 B0.b6`, `0x282 B2.b1`, `0x282 B3.b3`

这些观察只证明从 UI 风量 2 到 6 的敏感性；两个水平不足以恢复编码、位宽、比例，亦不能区分设定、目标或实际风机量。

### A/C UI 切换可逆相关

- `0x20C B1.b3`
- `0x2A1 B5.b0`
- `0x2A7 B7.b0`, `0x2A7 B7.b2`（反方向）
- `0x2BF B5.b3`, `0x2BF B5.b4`
- `0x361 B3.b1`（反方向）, `0x361 B3.b2`

这些观察在 S2→S3→S4 中逐轮可逆，只能称为与本轮 A/C UI 切换相关的 raw observation；不能据此命名为 `Cooling_enable`，也不能归入尚未确定控制层级的制冷请求、许可、执行或物理结果。

### 未保留分类

- `0x20C B4.b1` 在五轮 S0–S5 均为 0。它在 Round 3 的总体 ON 工况下曾变化，但本轮未响应任何预注册状态，因此当前证据不能给它分配总开关、风量或 A/C 类别。

完整逐轮轨迹见 `round3_group_state_detail.csv` 和 `round3_bit_disambiguation.csv`。

## 全总线补充观察

盲扫得到 93 个在五轮、六个稳态窗口中均满足同一模式且最低 bit 纯度不低于 95% 的 raw bit：26 个 HVAC/送风开启相关、21 个风量敏感、46 个 A/C 可逆相关。它们分布在多个字节和 CAN ID 中，但这个计数不是 Signal 数或独立 Evidence 数；同字节连续量、枚举、复制、派生值均可能贡献多个同步 bit。完整清单见 `all_bus_repeatable_bit_hypotheses.csv`，未纳入本轮对 16 个继承组的字段级存废裁决，也不直接提升为已识别字段。

## 转换层级

对 Round 3 的 16 个掩码组按预期方向匹配五个操作事件。下列数值是重建时间轴上的对齐偏移估计，不是控制响应延迟；人读报告按整秒能力概括，机器明细保留原始计算精度：

- E03 开启低档送风：从对齐不确定范围内至约 +2 s；原始负偏移只表示落在对齐不确定范围内，不解释为事件前变化。
- E05 风量 2→6：约 +1 至 +6 s。
- E07 打开 A/C：约 0 至 +3 s。
- E09 关闭 A/C：约 0 至 +5 s。
- E11 关闭 HVAC：约 0 至 +4 s。

原始逐轮方向、时刻与全程转换数在 `round3_group_transitions.csv`。这些偏移不能用于 ECU 级亚秒排序，也不能据早晚把字段命名为请求、许可或执行反馈。

## 外部 Evidence 与采集背景

- 照片显示环境温度 28°C、设定温度 20°C；S1/S2/S4 的 A/C 灰色，S3 的 A/C 蓝色，风量分别为 2/6/6/6，S0/S5 为 HVAC 关闭。
- S0023 的 E07 原拍与 E08 补拍均显示 A/C 蓝色、风量 6；补拍只改善可见性，不新增状态。
- 五轮间 session 记录空档为 87–143 s，与“约 1–2 分钟稳定等待及轮间复位操作”背景相容；这些轮是在相同采集设计和 UI 状态序列下的重复，未记录的车辆与环境条件不默认为完全一致。
- 音频采集均为 `DISABLED`，因此无法从本批资产核验用户提到的开始后约 4–6 s 微型电机式声音，也不能将 CAN 变化与该声音直接对齐。
- 没有固定出风温度、压缩机、电功率或压力 Evidence，本轮不确认实际制冷是否建立。

## 证据边界与未决问题

本轮证明的是 raw 值与已拍照 UI 状态在相同采集设计和 UI 状态序列下五轮重复中的可重复关联。未完整记录的环境和车辆条件不作一致性假设。仍不能确定：DBC 名称、字段真实边界/位宽/比例、发送 ECU、多个 ID 的源/复制/派生关系、风机或压缩机实际运行、制冷请求/许可/执行与保护状态，以及跨环境、车辆状态或软件版本的普适性。
